# weblley BU drive

WordPressサイト（データベース＋ファイル）のバックアップ・復元・サイト移行プラグイン。
将来的にGoogle Driveへの自動バックアップ（毎日深夜1時）に対応予定。

## 機能

- **手動バックアップ**: DB / uploads / themes / plugins を選択してZIP化（バックグラウンド実行・進捗表示付き）
- **ダウンロード / アップロード**: ZIPのダウンロードと、分割アップロードによるインポート（サーバーのファイルサイズ上限の影響を受けない）
- **復元**: ワンクリック復元。復元前に緊急DBダンプを自動取得、実行中はメンテナンスモード
- **サイト移行**: 別サイトのバックアップも復元可能
  - URL置換（シリアライズ対応・JSONエスケープ / URLエンコード / プロトコル相対 / www有無に対応）
  - テーブルプレフィックス変換（`wp_capabilities` 等の行データも修正）
- **安全設計**: manage_options＋nonce検証、Zip Slip対策、保管ディレクトリの直アクセス遮断、トークンのプレースホルダーエスケープ復元（`%` 破損防止）

## 使い方

1. `weblley-bu-drive` フォルダを `wp-content/plugins/` に配置して有効化
2. 管理画面「ツール > weblley BU drive」から操作

## 動作要件

- WordPress 6.0+ / PHP 8.0+（`ZipArchive` 拡張必須）

## 開発メモ

- DBダンプは「1行＝1ステートメント」形式の自前フォーマット（復元側でSQLパーサー不要）
- バックアップ・復元はループバックリクエストによるバックグラウンドジョブで実行し、進捗は `wbd_job` オプション経由でポーリング
- 画像・動画などの圧縮済み形式はZIPに無圧縮格納して高速化
